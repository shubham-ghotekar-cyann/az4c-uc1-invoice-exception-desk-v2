# AI coding tool settings

This repository includes settings for Claude Code, Cursor and GitHub Copilot. While you work on the
assignment, they record how you use these tools: the prompts you send, the files the assistant changes and the
commands it runs. The record is used only to assess this assignment.

## What to do

- Open this folder, or `code/`, as the project folder in your editor.
- If your editor asks whether to trust this project or allow its settings, please allow them.
- Keep these files in your repository exactly as provided, both here and in `code/`:
  - `.az4c/`
  - `.claude/settings.json`
  - `.cursor/hooks.json`
  - `.github/hooks/az4c-activity.json`

Please note that a submission in which these files have been removed or changed will not be graded.
